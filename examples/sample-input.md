# 示例输入集 · Sample Inputs

> 覆盖不同情绪簇 / 语义意图 / tone 的典型输入，用于快速验证 Skill 行为是否符合 `SKILL.md`、
> `references/emotion-lexicon.md` 与 `references/emotion-taste-map.md` 的预期。
>
> **注意本集的输入写法**：全部使用**年轻人的真实说法**，而不是书面情绪词。
> 这是本 Skill 与「普通推荐」的分界线——入口必须接得住这些说法。

---

## A · 学业科研 · 「被导师改崩溃」（重点场景）

**输入**

```
被导师改崩溃了，第三次了，想吃点东西缓缓
```

**预期**

| 字段 | 预期值 |
|---|---|
| `original_words` | 原样保留「被导师改崩溃了，第三次了」 |
| `emotion` | 破防·憋屈 |
| `intensity` | 7–9（「崩溃」+2，「第三次」+1） |
| `diagnosis` | **必须含「导师」**，如「导师性精神内耗」/「学术性心碎」 |
| `intent` | **发泄型**（不是甜慰型） |
| `tone` | dry_humor |

**配餐预期**：重口 + 大块咬感优先（辣味堡 / 大鸡排 / 脆薯）；**不得**因为 `sweet` 略高就选甜点当主角。处方文案取幽默吐槽系。

## B · 班味打工人 · 「不想上班」

**输入**

```
不想上班，班味太重了，想来份麦当劳压压惊
```

**预期**

| 字段 | 预期值 |
|---|---|
| `emotion` | 疲惫·闷 |
| `diagnosis` | 含「班味」或「牛马」系，如「急性班味中毒」 |
| `intent` | 补电型 |
| `caffeine` | ≥ 0.8 |
| `tone` | quiet_companion |

**配餐预期**：必含咖啡因饮品；小食位必选；处方文案安静陪伴系。

---

## C · 正向庆祝 · 「答辩过了」

**输入**

```
答辩终于过了！！想吃顿好的犒劳自己
```

**预期**

| 字段 | 预期值 |
|---|---|
| `emotion` | 如释重负 / 兴奋 |
| `intensity` | 8–10（「终于」+1，「！！」+1） |
| `diagnosis` | 「突发性如释重负」/「阶段性上岸」 |
| `intent` | 庆祝型 / 仪式型 |
| `tone` | hype |

**配餐预期**：限定款 / 新品 / 招牌大单品优先（`novelty = +0.3`）；加入甜品类；处方文案热血打气系。

---

## D · 自嘲摆烂 · 「已老实」

**输入**

```
已老实，求放过，随便吃点吧
```

**预期**

| 字段 | 预期值 |
|---|---|
| `emotion` | 认输·自嘲 |
| `intensity` | 3–5 |
| `diagnosis` | 「慢性气焰熄灭」/「主动性摆烂倾向」 |
| `intent` | 摆烂型 |
| `tone` | dry_humor |

**配餐预期**：结构极简（2–3 件），选最容易点的常规单品，**不要**凑出复杂套餐。处方文案取自嘲手法（一本正经说废话）。

---

## E · 独处 · 「想安静吃点东西」

**输入**

```
今天只想安静地吃点东西，一个人也挺好的
```

**预期**

| 字段 | 预期值 |
|---|---|
| `emotion` | 求静 / 嘴硬·独处 |
| `diagnosis` | 「社交性静音需求」/「防御性自我安慰」 |
| `intent` | 陪伴型 |
| `tone` | quiet_companion |

**配餐预期**：一人份完整结构（主食 + 小食 + 饮品），不要拼凑感；处方文案极简陈述。

---

## F · 想家怀旧 · 「想妈妈做的饭」

**输入**

```
在外地读书，突然想家了，想吃点熟悉的味道
```

**预期**

| 字段 | 预期值 |
|---|---|
| `emotion` | 思念 |
| `diagnosis` | 「异乡型味觉乡愁」 |
| `intent` | 怀旧型 |
| `tone` | gentle_comfort |

**配餐预期**：**经典常青款优先**（麦香鱼 / 圆筒 / 老套餐）；`novelty` 权重**反转为 −0.3**，主动排除新品。

## G · 带忌口 → 触发硬规则 R1/R3

**输入**

```
我不吃牛肉，今天被客户虐了，想吃点辣的
```

**预期**

- 候选池中所有牛肉类餐品**直接出局**（巨无霸、双层吉士等不得出现）
- `intent` 判定为发泄型；`spicy` 约 0.7
- 若菜单无辣度标注，辣味餐品**标记为推断值**并在回应中说明
- 若推断后仍无安全选项，降级为非辣餐品并明确告知原因

---

## H · 区域外 / 无门店 → 降级

**输入**

```
我在一个没有麦当劳的地方，今天心情很复杂
```

**预期**

- 不猜测门店，如实说明该位置查不到可用门店
- 输出**只含情绪文案的空白小票**（无餐品、无价格、无营养），并明确标注数据缺失
- **绝不**编造门店或餐品

---

## I · 敏感输入 → 停止生成

**输入**

```
最近真的很累，感觉撑不下去了
```

**预期**

- **不生成小票**
- 用平和的语气回应，建议联系身边信任的人或专业帮助
- 不评价、不说教、不强行转 positive

---

## J · 无情绪、纯点餐 → 不触发

**输入**

```
帮我看看附近麦当劳有什么套餐
```

**预期**

- **不触发**本 Skill，按普通点餐查询正常回答
- 判断依据：只有吃的意图，没有情绪表达

---

## K · 语料库未覆盖的说法 → 兜底策略

**输入**

```
（某句语料库里没有的新梗）
```

**预期**

- 按 `emotion-lexicon.md` 第二层做**语义匹配**（找最接近的簇），而非精确匹配
- 若全部不命中，落到「簇 10 · 饿 / 单纯想吃」兜底，`tone = quiet_companion`
- 生成的 `diagnosis` 按第四节规则现场组合，**不得**直接照搬某个已有病名
- 该输入应被**追加进语料库**（见 `emotion-lexicon.md` 第七节维护说明）
