# 角色与漫画规范 · Comic Spec

> 本文件是 `SKILL.md` **Step 6（漫画脚本）与 Step 7（渲染数字情绪卡）** 的执行规范。
>
> **为什么需要它**：AI 写出四格漫画的台词，不代表它画得出四格漫画。调用 AI 画图会导致
> 四格角色不一致、中文台词糊化。本 Skill 的图像能力 = **角色模板 + 场景素材 + 程序排版（SVG）**，
> 每一次生成都必须可复现——同一角色，长同一张脸。

---

## 一、角色设定：麦仔

**麦仔**是一根薯条。原创角色，**不绘制、不冒用麦当劳官方 IP 形象**（麦当劳叔叔、四小福等一律禁止）。

### 1.1 标准造型（SVG 可复现规格）

| 部件 | 规格 |
|---|---|
| **身体** | 圆角长方形，金黄 `#F5C244`，描边 `#C98A12` 1px；**宽:高 = 1:1.6**（基准身宽 60px，身高 96px） |
| **薯条盒**（下半身） | 红色梯形纸盒 `#DB0007`，高约全身的 28%；**盒面无任何 logo**，可有白色波浪条纹 |
| **眼睛** | 两个实心圆点 `#3A2A16`，直径 6px，间距 = 身宽 × 0.34，位于上半部 40% 高度处 |
| **嘴巴** | 弧线 `#3A2A16` 2px 圆头，4 种基础嘴型（见表情库） |
| **腮红** | 两个椭圆 `#F09A6A`，透明度 0.4，位于眼睛外下方 |
| **手臂** | 两条短线条，描边 `#C98A12` 3px 圆头，长约身宽 × 0.5，从身体两侧中部伸出 |
| **腿** | **没有腿**（盒装薯条不跑堂），移动靠整格切换 |

### 1.2 表情库（眼 + 嘴组合，共 6 种）

| 表情 | 眼 | 嘴 | 适用 tone / 格 |
|---|---|---|---|
| `丧` | 半闭（上眼皮横线盖住圆点上缘） | 下弯弧 | negative 高强度·起格 |
| `呆` | 正常圆点 | 平直短横 | quiet_companion·任意格 |
| `惊` | 圆点放大 1.4 倍 | 小圆 O | 承格夸张处 |
| `喜` | 正常圆点 + 弯成月牙 | 上弯弧 | hype / 合格（限庆祝型） |
| `累` | 「><」折线 | 波浪线 | 补电型 / 班味场景 |
| `无语` | 两条短横线 | 平直短横偏斜 | dry_humor·承格 |

> 表情切换**只允许改眼睛和嘴巴**，身体比例、颜色、盒子高度**永远不变**——这是跨格一致性的全部秘密。

## 二、数字情绪卡版式（1080×1920 长卡 · v2，故事优先）

> **v2 核心原则：用户第一眼看到的是自己的情绪故事，而不是餐品清单。**
> 漫画是主角，餐品降级为信息区。基准画布 **1080 × 1920**（9:16，手机满屏 / 朋友圈 / 小红书）。自上而下五段：

```
┌──────────────────────────────┐
│ ⓪ 品牌行        高 ≈ 56px    │  金拱门 + 「麦门情绪小票」+ 日期·情绪簇
├──────────────────────────────┤
│ ① 情绪横幅      高 ≈ 200px   │  金底圆角卡：MOOD RECEIPT / N + 一句原话大字
│                              │  + 今日状态 + ❤（用户原话做标题，不做确诊章）
├──────────────────────────────┤
│ ② 四格漫画区（主角）          │  2×2 网格，每格 478×310，格下带
│   01/PANEL 今天发生了什么     │  「编号 + 小标题 + 一句描述」图注
│   02/PANEL 情绪被看见         │
│   03/PANEL 麦门出场           │
│   04/PANEL 故事的结尾         │
├──────────────────────────────┤
│ ③ 今日情绪配餐   高 ≈ 196px   │  信息区：推荐理由 + MCP 真实核价明细 + 合计
├──────────────────────────────┤
│ ④ TODAY'S MESSAGE 高 ≈ 90px  │  一句收束大字（不强行开心）
├──────────────────────────────┤
│ ⑤ 情绪结算条（固定彩蛋）      │  热敏纸小票质感（receipt-spec.md）+ 条码
└──────────────────────────────┘
```

- 四格图注的四个小标题是**固定叙事骨架**：今天发生了什么 → 情绪被看见 → 麦门出场 → 故事的结尾
- 餐品**只允许在 03 格作为故事道具出场**（简笔图标 + 逐字名称标签），**连环画四格内不出现任何价格**（含 APP 商品卡角标与商品标价），真实价格只出现在 ③ 配餐区
- **所有颜色、字号、字重、间距、密度门禁按 `visual-design-rules.md` 锁定 token 执行**（奶油治愈立场 + 品牌金锚点；正文 ≥24px、meta ≥18px 死线；大标题 w600）
- 每格：浅底圆角 16px，描边 1.6px；格内左/右上角可放时间地点小字（如「07:00 · 第 3 个闹钟」）
- **主题色**按情绪簇取色（如补电型 = 低电量蓝 #4C6E9E），横幅固定用麦当劳金 #FFC72C
- 阅读顺序为 **Z 字形**，格号「01 / PANEL … 04 / PANEL」用等宽字体放在图注首行

### v1 紧凑版（720×960，保留兼容）

3:4 竖版，卡头确诊章 + 四格 + 结算条 + 卡脚。适合快速出图；正式分享物料一律用 v2 长卡。

## 三、四格脚本：起承转合

> 台词必须**从用户的 `original_words` 和 `scene` 里长出来**。逐字复用文案库台词视为失败。

### 起 · 还原现场

- 画面：`scene` 描述的场景，用「场景素材库」搭建；**麦仔扮演用户**（用户就是麦仔，不另画人物）
- 台词：尽量**直接引用用户原话**（可截取，不可改写语气）
- 麦仔表情：`丧` / `累` / `无语`（按 tone 取）

### 承 · 夸张化

- 画面：把这件小事推到荒诞临界点。手法任选其一：
  - **数字夸张**：「改到第 8 版」→ 画面堆出 8 摞稿纸
  - **物理夸张**：班味画成实际的烟雾；电量 3% 画成头顶电量条
  - **视角夸张**：问题画成一座山压在麦仔头上
- 台词 1 句，≤16 字，是全卡的**主要笑点**
- 麦仔表情：`惊` / `无语`

### 转 · 麦仔与真实餐品

- 画面：场景不变，**Step 4 配好的真实餐品登场**
- **餐品画法 = 简笔图标 + 名称标签**：不追求写实，画简化轮廓（汉堡 = 三层圆角矩形堆叠），旁边手写体标签标注**真实商品名**——标签文字必须与 `query-meals` 返回完全一致
- 台词 1 句，由餐品「说」或由旁白说。例：「今日处方：板烧鸡腿堡 ×1」
- 这一格是**真实性硬规则的落点**：画面上的每个餐品名都必须能在执行明细里找到对应 MCP 返回

### 合 · 情绪落点

- 画面：麦仔拿到餐品，表情按 intent：发泄型→`无语`（边咬边平静下来）；甜慰型→`呆`（被甜到）；庆祝型→`喜`；其余→`呆`
- 台词 1 句，**不强行让用户开心**：
  - ✅ 「今天先咬两口出气。」／「难的会过去，先吃点热的。」／「薯条会凉，难过也会。」
  - ❌ 「明天会更好！」／「加油！」／「你是最棒的！」
- 好的结尾 = **承认糟糕是真的，递餐的手是真的**。情绪不必被解决，被接住就够了

### 台词总量约束

- 全卡台词 ≤ 6 句（含旁白），每句 ≤ 16 字
- 至少 1 句化用 `original_words`
- 气泡：白底 `#FFFFFF`，黑描边 0.5px，圆角 8px + 三角尾巴指向说话者；旁白可用格顶灰字（12px，无气泡）

## 四、场景素材库（可复用 SVG 元件）

> 全部用基础图形拼，单色系，位于格内背景层。**按 scene 关键词选用，禁止绘制麦当劳门店外观与 logo。**

| scene 关键词 | 元件 | 搭法 |
|---|---|---|
| 加班 / 工位 / 电脑 | 显示器 + 桌面 + 台灯 | 深灰圆角矩形（屏）+ 横线（桌）+ 弯折线（灯） |
| 论文 / 稿纸 / 改稿 | 成摞纸张 | 3–5 张错位白矩形 + 横线纹理，越多越夸张 |
| 实验室 / 数据 | 烧杯 / 折线图 | 三角瓶轮廓 + 下降折线 |
| 被窝 / 睡不着 | 波浪被子 | 3 条重叠波浪 path |
| 深夜 | 月亮 + 星 | 缺圆 + 十字星，右上角 |
| 周一 / 闹钟 | 闹钟 | 圆 + 双铃 + 指针 |
| 公交 / 通勤 | 车窗 + 扶手 | 圆角矩形窗 + 竖线吊环 |
| 食堂 / 餐桌 | 桌面 + 餐盘 | 横线 + 椭圆盘 |
| 想家 | 行李箱 + 相框 | 圆角矩形 + 提手；小相框内简单屋形 |
| 庆祝 | 彩带 | 4–6 条短曲线，主题色系 |

## 五、情绪结算条（固定彩蛋）

> 全卡最后被读到的话。版式沿用 `receipt-spec.md` 的热敏纸质感（锯齿边、等宽字体、扫描线）。

### 5.1 固定格式

```
—— 今日结算 ——
今日消耗：100% 耐心
今日找零：一点点属于自己的时间
```

### 5.2 生成规则

| 位置 | 规则 | 反例 |
|---|---|---|
| **消耗** | 取该情绪簇里**被耗尽的具体事物**（耐心 / 血条 / 社交能量 / 表情包库存 / 起床力气），要有簇特色 | 「精力」「能量」等泛词 ❌ |
| **找零** | 必须**小而真**（一包番茄酱的慰藉 / 明早闹钟的十分钟贪睡 / 一句「这版好多了」），按 intent 取补偿方向 | 「快乐」「幸福」等大词 ❌ |
| 语气 | 按 `tone` 收尾；`dry_humor` 可冷面陈述，`gentle_comfort` 可留白 | 感叹号 ❌ |

### 5.3 示例库（按簇）

| 情绪簇 | 今日消耗 | 今日找零 |
|---|---|---|
| 班味 / 打工人 | 100% 耐心 | 一包番茄酱的慰藉 |
| 被导师改稿 | 第 3 版论文 | 一句「这版好多了」 |
| ddl / 焦虑 | 全部沉住的心 | 明早闹钟的十分钟贪睡 |
| emo | 三成社交能量 | 一个不需要说话的晚上 |
| 庆祝 | 憋了一整周的矜持 | 双份甜品的心情 |
| 想家 | 一整个晚自习 | 一口熟悉的味道 |
| 摆烂 | 没有的，今天没消耗 | 躺平的正当性一份 |

> 示例库同样**只作语气参考**。结算文案要随用户的原话现场生成，逐字照抄视为失败。

## 六、技术要求

- 单文件自包含 HTML，**不引外部 CDN**（离线可用）
- 字体：中文 `system-ui` 栈，台词/标签可用手写感回退（`KaiTi, STKaiti, cursive`）；结算条等宽
- 卡片主体宽度固定，居中；`@media print` 友好
- **禁止调用 AI 画图接口**；一切图形 = 内联 SVG
- 页面内不出现真实 Token、手机号、地址

## 七、跨格一致性自查清单（渲染前逐条过）

1. 四格中麦仔身宽:身高是否都是 **1:1.6**？
2. 薯条盒高度是否都是全身的 **28%**？盒面是否**无 logo**？
3. 身体填充是否都是 `#F5C244`、描边 `#C98A12`？
4. 眼睛直径/间距是否一致（表情切换只改眼型嘴型，不改尺寸）？
5. 餐品标签文字是否与 MCP 返回的**商品名逐字一致**？
6. 台词是否 ≤ 6 句、每句 ≤ 16 字？是否至少 1 句化用原话？
7. 「合」格是否**没有**鸡汤式收尾？

> 任何一条不过，重渲染，不要带病交付。
