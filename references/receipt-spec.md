# 小票版式规范 · Receipt Spec

> **本规范的现行角色**：小票不再整卡输出，而是作为数字情绪卡底部的**「情绪结算条」**（固定彩蛋）——
> 锯齿边、热敏纸质感、等宽字体、扫描线纹理全部保留。卡的整体版式见 `comic-spec.md` 第二节。
> 卡头标题区、确诊章等元素仍适用于结算条上方区域。（v2）

> 本文件是 `SKILL.md` Step 7（渲染数字情绪卡）中**情绪结算条**的视觉依据。目标是：**任何人按这份规范生成的结算条，看起来都是同一张小票。**
>
> v2 变更：引入**情绪主题色系统**、确诊章、金色拱门、药房印章、楷体处方与热敏纸纹理。基准实现见 [`../assets/receipt-sample.svg`](../assets/receipt-sample.svg) 与 [`../assets/receipts-gallery.svg`](../assets/receipts-gallery.svg)。

---

## 一、画布与基础

| 项 | 值 |
|---|---|
| 宽度 | 固定 `340px`，居中 |
| 高度 | 自适应内容，无固定值 |
| 纸色 | `#FCF9F2`（暖纸白） |
| 描边 | `1px solid #DDD5C4` |
| 圆角 | 0（收银小票是直角） |
| 正文字体 | `SFMono-Regular, Menlo, Consolas, "Microsoft YaHei", monospace` |
| 处方字体 | `KaiTi, STKaiti, 楷体, serif`（手写信件感） |
| 文字色 | `#26221C`（主）/ `#8D8577`（弱） |
| 点缀金 | `#FFC72C`，仅用于金色拱门 logo |

**热敏纸纹理**：整张纸覆盖间距 3px、透明度 2.8% 的横向扫描线（SVG pattern 或 CSS repeating-linear-gradient），远看几乎不可见，近看有「打印纸」的质感。

**锯齿边**：上下边缘 6px 齿距、4.5px 齿深的撕纸边。

**不允许**：渐变、阴影、发光、圆角卡片、彩色背景块。这张小票必须是「纸」。

---

## 二、情绪主题色系统（v2 核心）

每张小票根据情绪选择一个主题色 `T`，用于：确诊章、强度圆点、区块标题、合计金额、处方竖线、药房印章。

| 情绪 | 主题色 | 色值 |
|---|---|---|
| 疲惫 / 班味超标 | 加班蓝 | `#4C6E9C` |
| 兴奋 / 庆祝 | 麦门红 | `#DB0007` |
| 低落 / emo | 安慰粉 | `#D9719A` |
| 焦虑 / 压力大 | 焦躁紫 | `#7B6BC9` |
| 思念 / 想家 | 炉火橙 | `#E08A3C` |
| 平静 / 其他 | 麦门红（默认） | `#DB0007` |

主题色必须低饱和、偏「墨水感」，**禁止使用荧光色**。同一张小票上主题色不超过 6 处。

## 三、区块顺序（固定，不可调换）

```
① 抬头区（金拱门 + 标题）
② 元信息区（单号 / 门店）
③ 情绪诊断区（确诊章 + 强度圆点 + 场景）
④ 餐品明细区（点线价签）
⑤ 合计区（今日份心情）
⑥ 营养小结区（紧凑两行）
⑦ 灵魂处方区（楷体 + 药房印章）
⑧ 条码区 + 撕拉线
⑨ 落款
```

### ① 抬头区

```
        ★金拱门★            ← SVG 双拱 M，金色 #FFC72C，高 30px，居中
       灵 魂 小 票           ← 21px, 700, #26221C, letter-spacing 3px, 居中
       SOUL RECEIPT         ← 7.5px, 400, #8D8577, letter-spacing 5px, 居中
```

金拱门用 path 绘制（两个相连抛物线拱），**不要用字母 M 代替**。

### ② 元信息区

两行，右对齐排版（标签左、值右）：

```
单号   SR-20261014-2107      ← 9px 弱色
门店   广工西生活区店          ← 值 9px 主色
```

- 单号格式：`SR-{YYYYMMDD}-{4位序号}`
- 门店名：**必须来自 `query-nearby-stores` 的真实返回**（可缩写，去掉「麦当劳广州」前缀）

### ③ 情绪诊断区（v2 重做，全票视觉重心）

标题 `情绪诊断`（10.5px, 700, 主题色）+ 右侧点线延伸。

**确诊章**：`确诊 · {情绪名}`，18px 700 主题色，外框 2.4px 主题色圆角矩形（rx 3），整体旋转 -1.3°，左侧对齐。这是「确诊体」梗的视觉化——章要像盖章，不要像标签。

**强度圆点**：10 个直径 7.2px 的圆点，间隔 10.5px；填充主题色，空心 `#DDD5C4`；右端标注 `8/10`（9px 弱色）。**禁止用 `█` 字符**。

**场景**：标签 9px 弱色 + 值 10px 主色，如 `场景  加班到十点`。

### ④ 餐品明细区

标题 `为你配的餐`。每行：名称（10.5px 主色）+ **点线引导线** + 价格（11px 主色，右对齐）：

```
板烧鸡腿堡 ·················· 24.00
麦乐鸡5块 ··················· 14.50
```

- 点线引导线：`1.2px dotted #DDD5C4`，`dasharray 1.5 3.5`，连接名称末尾与价格前方
- 价格保留 2 位小数
- **不设数量列**（本 Skill 配餐均为单份；多份时在名称后缀 `×2`）

### ⑤ 合计区

```
今日份心情                ¥ 48.50
```

- 「今日份心情」10px `#8D8577`（固定文案，**不可改动**）
- 金额 17px, 700, **主题色**，右对齐
- 若 `calculate-price` 返回 `discount > 0`：加一行 9px 主题色 `已省 ¥{X}（{商品}促销中）`——**优惠必须来自真实返回，不得虚构**

### ⑥ 营养小结区（v2 压缩为两行）

```
能量 619 kcal · 蛋白质 36 g · 脂肪 29 g
碳水 51 g · 钠 1465 mg
```

- 9px `#8D8577`，紧凑两行，不再逐行排
- **必须来自 `list-nutrition-foods` 真实返回**
- 数据整体缺失时**整块省略**，不留空表、不填 0
- 个别餐品缺失时（如口味款甜品无营养条目）：其余餐品照常合计，并加一行 8px 脚注 `* XX 营养未收录，未计入合计`，**不取近似值补齐**

### ⑦ 灵魂处方区（v2 重做，情绪温度所在）

标题 `灵魂处方`。正文 **楷体 14px `#26221C`**，行高 24px，左侧 3.5px 主题色竖线：

```
│ 今天已经很努力了。
│ 吃饱，明天再战。
```

- **两行、每行不超过 14 字**
- 不再用引号包裹，竖线即「处方笺」的视觉隐喻
- 处方文案从 `emotion-taste-map.md` 语气矩阵中选取，**禁止现场发挥**

**药房印章**（v2 新增）：圆形双环（外环 2px、内环 0.8px，直径 68px），环形文字 `SOUL PHARMACY · 麦门灵魂药房 ·`（7.5px, 700, letter-spacing 1.2px，沿上弧排布），中心金色拱门 + `MD'S`。整体旋转 -14°，透明度 0.62，主题色，盖在处方区右侧。**印章是「药房开出处方」的仪式感来源，不可省略。**

### ⑧ 条码区 + 撕拉线

- 伪随机条码：SVG 矩形，高 26px，条宽 1–3px，间隙 1–3px，总宽 ≤262px，居中
- 下方一行：`20261014 2107`，8.5px `#8D8577`，letter-spacing 2px
- **禁止使用真实条码字体或外部条码库**
- 撕拉线：`┈┈┈┈ ✂ ┈┈┈┈`，两侧点线 + 居中剪刀符号（11px `#8D8577`）

### ⑨ 落款

```
本小票不能报销，但可以报销心情
```

9px `#8D8577`，居中，固定文案，**不可改动**。

---

## 四、分隔线

区块之间一律用虚线：`1px dashed #DDD5C4`，`dasharray 3 3`，左右各留 24px 边距。区块标题右侧的延伸线用更细的点线（`dasharray 2 3`）。

**不允许**：实线、双线、彩色分隔线。

---

## 五、输出要求

| 项 | 要求 |
|---|---|
| 文件名 | `soul-receipt-{YYYYMMDD}-{4位序号}.html` |
| 自包含 | 单文件，**不引用任何外部 CDN / 字体 / 图片**（离线可开） |
| 打印友好 | `@media print` 下去掉页面背景，仅保留小票本体 |
| 响应式 | 视口小于 340px 时不出现横向滚动 |
| 隐私 | 页面内**不得出现**真实 Token、手机号、详细地址、用户真实姓名 |
