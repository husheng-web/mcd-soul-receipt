# 情绪 → 口味 映射表 · Emotion-Taste Map

> 本文件是 `SKILL.md` Step 1（情绪转译，**在 `emotion-lexicon.md` 之后**）与 Step 4（配餐打分）的参数依据。
> 所有数值都是**可调参数**，不是客观真理。调整时保持同一行的相对关系即可。

---

## 一、情绪参数 Schema

### 输出 Schema

```json
{
  "emotion": "string, 用用户自己的词",
  "polarity": "positive | negative | neutral",
  "intensity": "0-10 整数",
  "scene": "string, 具体场景短语",
  "taste_vector": { "fried": 0-1, "sweet": 0-1, "caffeine": 0-1, "spicy": 0-1, "light": 0-1 },
  "tone": "gentle_comfort | dry_humor | hype | quiet_companion"
}
```

### `intensity` 上调信号

| 信号 | 加值 |
|---|---|
| 出现「已经」「终于」「又」「还是」 | +1 |
| 出现重复标点（！！！、。。。） | +1 |
| 出现极端词（崩溃、爆炸、绝了、疯） | +2 |
| 语气平淡、无标点、短句 | −2 |
| 出现「有点」「稍微」「还行」 | −2 |

基准：陈述句为 5。最终取值夹在 0–10。

### `scene` 生成规则

由情绪 + 上下文反推，必须是**具体场景**，不能是泛词。

| 用户说 | scene（✅） | scene（❌ 泛词） |
|---|---|---|
| 「加班到现在」 | 加班到十点 | 工作 |
| 「答辩终于过了」 | 毕业答辩结束 | 学习 |
| 「跟对象吵架了」 | 和对象冷战 | 感情 |
| 「今天好无聊」 | 周末一个人在家 | 生活 |

## 二、情绪 → 口味向量

| 情绪簇 | fried | sweet | caffeine | spicy | light | tone |
|---|---:|---:|---:|---:|---:|---|
| 疲惫 / 班味超标 | 0.8 | 0.3 | **0.9** | 0.2 | 0.1 | quiet_companion |
| 委屈 / emo | 0.4 | **0.8** | 0.2 | 0.1 | 0.4 | gentle_comfort |
| 焦虑 / 压力大 | 0.7 | 0.4 | 0.5 | 0.3 | 0.1 | dry_humor |
| 愤怒 / 破防 | 0.9 | 0.2 | 0.4 | **0.7** | 0.0 | dry_humor |
| 兴奋 / 庆祝 | 0.5 | **0.7** | 0.3 | 0.4 | 0.2 | hype |
| 空虚 / 无聊 | 0.5 | 0.5 | 0.4 | 0.4 | 0.3 | dry_humor |
| 思念 / 想家 | 0.3 | 0.6 | 0.2 | 0.3 | 0.5 | gentle_comfort |
| 平静 / 无特别情绪 | 0.4 | 0.4 | 0.4 | 0.3 | 0.4 | quiet_companion |
| 饿 / 单纯想吃 | 0.5 | 0.4 | 0.3 | 0.4 | 0.3 | quiet_companion |

> 加粗 = 该行的主导维度。配餐时优先保证主导维度命中。

### 口味维度含义

| 维度 | 对应餐品特征 |
|---|---|
| `fried` | 薯条、麦乐鸡、派等油炸小食 |
| `sweet` | 圆筒、派、奶昔、甜品类 |
| `caffeine` | 拿铁、美式、茶类等含咖啡因饮品 |
| `spicy` | 辣味 burger、辣味小食（**菜单若无标注，视为推断值**） |
| `light` | 沙拉、玉米杯、无糖茶等清爽选项 |

## 三、配餐硬规则

在打分之前，先过这三条**一票否决**规则：

| # | 规则 | 说明 |
|---|---|---|
| R1 | **忌口一票否决** | 用户声明不吃牛肉 / 猪肉 / 辣 / 素食等，含该成分的餐品直接出局，不参与打分 |
| R2 | **咖啡因强制** | `caffeine > 0.6` 时，饮品位必须选含咖啡因饮品；无可用则明确说明 |
| R3 | **忌口数据不确定时保守** | 菜单无法判断某餐品是否含用户忌口成分时，**不选该餐品** |

### 结构

| 位置 | 数量 | 说明 |
|---|---|---|
| 主食 | 必选 1 | 汉堡 / 卷 / 饭 |
| 小食 | 可选 1 | 由 `fried` 主导时必选 |
| 饮品 | 必选 1 | 受 `caffeine` / `sweet` 影响 |
| 甜品 | 可选 1 | 由 `sweet > 0.6` 时加入 |

### 打分公式

```
score = Σ_k  taste_vector[k] × tag_k(餐品)
        + 0.3 × novelty(餐品)
        − 0.5 × price_penalty(餐品)
```

- `tag_k(餐品)` ∈ [0,1]，由名称 / 分类 / 标签推断，**必须标记为推断值**
- `novelty`：限定款、新品、季节款 = 1，常规款 = 0
- `price_penalty`：单价高于该类目中位价 1.5 倍 = 1，否则 0
- 同分时优先选名称更具体、分类更明确的餐品

## 四、语气基调（tone）矩阵

| tone | 中文名 | 适用 | 语言特征 |
|---|---|---|---|
| `gentle_comfort` | 温柔安慰 | negative + 中高强度 | 短句、少形容词、不追问 |
| `dry_humor` | 幽默吐槽 | negative + 低强度，或 neutral 偏丧 | 一本正经地说废话 |
| `hype` | 热血打气 | positive | 具体地夸，不空喊口号 |
| `quiet_companion` | 安静陪伴 | neutral，或 negative 但用户不想聊 | 极简，只陈述 |

**错配检查**：`negative` + 高强度 绝不允许 `dry_humor`（会显得嘲讽）。

## 五、文案库（语气参考，**非模板**）

> 约束：**两行、每行不超过 14 字**。以下为示例库。
> ⚠️ 改型后本库的角色：**只用于校准语气**（漫画台词与情绪结算条）。SKILL.md Step 6 规定：
> 根据用户具体经历现场创作，**逐字复用库内台词视为失败**。

### gentle_comfort · 温柔安慰

- 「今天已经很努力了。／ 吃饱，明天再战。」
- 「难过的日子总会过去。／ 先吃点热乎的。」
- 「你已经做得很好了。／ 剩下的交给明天。」
- 「不用逞强。／ 这里没人认识你。」
- 「辛苦了。／ 这份是你的。」
- 「慢一点没关系。／ 麦当劳不关门。」

### dry_humor · 幽默吐槽

- 「生活把你按在地上摩擦。／ 但薯条还是热的。」
- 「今天也是被选中的一天。／ 被甲方选中。」
- 「情绪不稳定？／ 那就吃稳定一点的。」
- 「世界很吵。／ 但巨无霸不会。」
- 「你已经很强了。／ 强到需要补充碳水。」
- 「老板不懂你。／ 但这份套餐懂。」

### hype · 热血打气

- 「你熬过的夜，／ 都变成了今天的底气。」
- 「这顿你值得。／ 明天继续赢。」
- 「恭喜。／ 但这还不是终点。」
- 「所有的准备，／ 都在今天兑现了。」
- 「记住这个瞬间。／ 下次还要这么赢。」
- 「今天你说了算。／ 麦当劳听你的。」

### quiet_companion · 安静陪伴

- 「不说话也没关系。／ 吃完再走。」
- 「今天的你就很好。／ 不用更好。」
- 「一份套餐，／ 一段安静的时间。」
- 「没什么大事。／ 就是想吃点东西。」
- 「坐一会儿。／ 不用急着回去。」
- 「麦当劳一直开着。／ 你随时可以来。」

## 六、敏感输入处理

| 输入特征 | 处理 |
|---|---|
| 自伤 / 轻生倾向的表达 | **立即停止生成小票**，用平和语气回应，建议联系身边信任的人或专业帮助（如心理援助热线） |
| 涉及疾病、体重焦虑、身材 | 不生成「营养小结」区块，不评价身材 |
| 涉及他人（想给某人点餐） | 可生成，但小票上不出现真实姓名，用「给一位很重要的人」代替 |
| 输入与吃完全无关且无情绪 | 不触发本 Skill |

> **一张小票不解决情绪问题，人才能。** 本 Skill 的定位是「陪伴与仪式感」，不是心理干预。
