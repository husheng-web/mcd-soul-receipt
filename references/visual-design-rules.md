# 麦门情绪小票 · 视觉设计系统 v1（锁定）

> 本文件是**硬规范**，不是参考。出图前锁定 token，出图后跑密度门禁，全 PASS 才交付。
> 设计立场由「视觉设计套件（visual-suite）」的设计系统蒸馏，并**适配麦当劳品牌**：
> 品牌金/品牌红为不可替换的锚点，其余全部收进**奶油治愈（莫兰迪）**立场。
> 根因提醒：廉价感不是"AI 做的"，是**没人做设计决定**。沉默 = 默认廉价值。

---

## 一、立场：奶油治愈（Cream Soft）+ 麦当劳品牌锚点

- 为什么：本 Skill 交付的是**情绪价值**，不是促销物料。高饱和撞色 + 拟物渐变 = 促销海报；低纯度中明度 + 奶油纸 + 圆角柔和 = 治愈。
- 允许圆角（这是奶油风格的特权）：卡片 20–24px、内容块 16–18px、标签 8–10px。
- 禁阴影（除热敏纸条极淡一层）、禁渐变（品牌金也不加渐变）、禁玻璃拟态。
- 参考风格卡：`styles.md` 第 4 项（奶油温柔）；**若用户明确要"更抓眼/更年轻"**，可整卡切到第 5 项（多巴胺 Y2K，允许粗黑标题 + 大色块），但**一套卡只能一个立场，不混用**。

## 二、锁定配色（只用这些 hex，禁自定义）

### 禁用清单（出现即返工）

- ❌ 蓝→紫 / 深蓝科技渐变（头号 AI tell）
- ❌ 渐变文字、玻璃拟态、发光状态点
- ❌ 同框 >3 个色相（含品牌层）：**品牌金 + 品牌红 + 主题色 = 3 个，已到上限**
- ❌ 纯黑正文、低对比浅灰正文、深底蓝字
- ❌ emoji 当图标（要图标就画线描 SVG，stroke 1.6，圆角端）

## 三、中文层级（1080px 宽长卡专用）

**铁律：字号越大，字重越轻。** 大标题上 800/900 黑体 = 瞬间掉到"廉价 banner"。奶油立场的标题用 w600–700（仅多巴胺立场允许 900）。

| 角色 | 字号 | 字重 | 字体 |
|---|---|---|---|
| 卡头大标题 Display | 64–72px | **600** | 无衬线 |
| 卡头副标（今日状态） | 26–28px | 400 | 无衬线 |
| 横幅 kicker（`MOOD RECEIPT / 003`） | 20px | 600 | mono + 字距 0.2em 大写 |
| 四格对白 | 22–24px | 600 | 无衬线 |
| 四格商品名称标签 | 20–21px | 700 | 无衬线 |
| 四格角落 meta（时间·地点） | 18–20px | 400 | mono |
| 配餐区标题 | 30–32px | 800 | 无衬线 |
| 配餐区行名 / 价格 | **21px**（2026-10-14 反馈：明细字小一点） | 400 / mono | 价格 mono |
| 配餐区 推荐理由 / 情绪基调 | 20–21px | 400 | muted |
| 券条文字 | 20px | 600 | — |
| TODAY'S MESSAGE | 40–44px | 600 | 无衬线 |
| 结算条标题 | 28px | 800 | 字距 0.3em |
| 结算条 标签 / 值 | 22px / 26px | 400 / 700 | 标签 mono |
| 卡脚 | 18–20px | 400–700 | mono / 无衬线 |

### 最小字号死线（手机可读，硬门禁）

- 正文 **≥24px**，说明/来源 ≥20px，meta/caption/水印 **≥18px**。
- **绝不出现 12/13/14/15/16/17px 的字**——手机上根本看不清 = 白做（v1 卡片曾满屏 12–15px，是本轮返工的主因）。
- 放不下就删字，**绝不缩字号**。行数不够就砍句子。

## 四、间距 token（只用这些值）

`8 / 12 / 16 / 24 / 32 / 40 / 48 / 64 / 80 / 96`（px）

- 页边距 48；块间距 24 / 32 / 40；行内 12 / 16。
- 主标题下 ≥32px，小标题下 ≥16px。
- 不许出现 18/22/26/30/35 这类随手写的间距。

---

## 五、密度门禁（治死空白）

- 内容纵向跨度 **≥80% 画高**；**任何单块无理由空白 ≤15% 画高（≤288px @1920）**。
- 4 带自检（各 480px）：底部带（75–100%）必须有实质内容；相邻两带不同时空；整体填充 ≥75%。
- 内容少时按阶梯修：**扩内容 → 加结构化承载（账本行/时间线/对比表）→ 换骨架 → 换画幅**。
  ❌ 绝不用装饰 blob / 无关插画 / 无脑放大标题填空。
- 渲染后必跑：
  ```bash
  python card_audit.py audit -f assets/comic-card-03.png
  ```
  全 PASS 才算交付；FAIL 就按上面阶梯修再渲。

## 七、卡面信息纪律（2026-10-14 用户反馈新增）

- **卡面不出现"运维/溯源"性质的信息**：取数来源（`数据来源：麦当劳 MCP 实时返回 · 门店 XXX`）、券有效期（`有效期至 XX-XX`）、「真实卡包在售」之类的系统口吻文案，一律**不上卡**。
- 真实性与溯源放在**卡脚一行**（`mcd-soul-receipt · 餐品与价格来自麦当劳 MCP 真实数据`）和对话的「执行明细」里，卡面只讲情绪与故事。
- TODAY'S MESSAGE 的 kicker 与正文大字之间**保持 ≥56px 间距**（两行要分开读）。

## 八、落地链路（与 SKILL.md 的 Step 6「出图与交付」一致）

1. 锁 token：立场、配色（基础层 + 品牌层 + 1 个情绪色）、字号表、间距 token → 写进生成器的常量区。
2. 内联 SVG 参数化绘制（零 AI 画图）→ 存 `assets/*.svg`。
3. Chrome headless 先出 1x 预览自查 → 再出 2x 交付图。
   ```bash
   chrome --headless --disable-gpu --screenshot=preview.png --window-size=1080,1920 file:///.../card.svg
   chrome --headless --disable-gpu --screenshot=card.png --window-size=1080,1920 --force-device-scale-factor=2 file:///.../card.svg
   ```
4. `card_audit` 密度门禁 → PASS。
5. 按第六节自审打勾 → 交付。

> 生成器可复用脚本：`gen_comic_card.py`（基础图形/角色/文案原语）+ 各卡 `gen_card_v*.py`。
> 设计 token 一旦锁定，**同一批卡全程不换色不换立场**（换色 = 散、乱、廉价）。
